# Cómo participar

Gracias por el interés en Iterador CEV.

## Errores e ideas: sí

Abre un [Issue](../../issues/new/choose). Para un error, ayuda mucho incluir:

- la versión (botón «Acerca de») y la versión de Windows;
- los pasos para que el error vuelva a ocurrir;
- la unidad guardada (`unidad.json`, botón Guardar) y, si el programa se cerró,
  `%LOCALAPPDATA%\IteradorCEV\registro.txt`.

## Código: por ahora no

El proyecto **no acepta pull requests** por el momento: se cierran automáticamente sin
revisión. Así los autores conservan la autoría completa del código y pueden decidir con
libertad la licencia de versiones futuras.

## Forks: sí

Puedes hacer un fork y modificarlo según la licencia [AGPL-3.0](LICENSE): si lo distribuyes
o lo ofreces como servicio en red, debes publicar su código bajo la misma licencia. Usa otro
nombre para tu versión (ver [NOTICE.md](NOTICE.md)).
